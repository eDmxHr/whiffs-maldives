# Admin Workspaces

## Admin UX Principles

- Fewer clicks
- Preserve context
- Surface problems before the owner searches for them
- Use consistent workspace patterns
- Support keyboard navigation and future command palette actions
- Keep business logic outside presentational components

## Dashboard

Purpose:

> Tell the owner what happened, what needs attention, and how the business is performing.

Core areas:

- Actionable inbox
- Revenue today and this month
- Orders today and this month
- Average order value
- Pending payments
- Orders to prepare
- Order pipeline
- Sales chart
- Bottle health
- Packaging inventory health
- Best sellers by revenue and quantity
- Catalog completeness
- Collection value and potential revenue
- Recent orders
- Recent activity
- Quick actions

## Orders Workspace

Desktop pattern:

- Order list on the left
- Order detail or inspector on the right
- Filters and search at the top

Core areas:

- Smart status filters
- Search by order number, customer, phone, fragrance, or brand
- Customer and delivery details
- Order items and stock visibility
- Payment review
- Fulfillment checklist
- Bottle allocation preview
- Packaging requirements
- Timeline and internal notes
- Partial fulfillment actions
- Preparation mode

Primary actions:

- Verify payment
- Reject or request payment proof
- Edit unpaid order
- Start preparation
- Mark ready
- Mark delivered
- Cancel or partially fulfill

## Fragrance Workspace

Purpose:

> Curate and manage the fragrance catalog.

Core areas:

- Fragrance list and search
- Metadata completeness/readiness
- Identity and classification
- Rich editorial content
- Images and drag-to-reorder gallery
- All fragrance notes
- Main accords
- Performance
- Climate, season, occasion, and time suitability
- Fragrance DNA scores
- Offerings and pricing
- Related bottles
- SEO
- Activity history

## Bottle Workspace

Purpose:

> Manage physical inventory and bottle profitability.

Core areas:

- Search and health filters
- Purchase details
- Supplier
- Original and usable volume
- Remaining and deducted volume
- Visual bottle gauge
- FIFO position
- Bottle ledger
- Orders fulfilled
- Revenue generated
- Estimated remaining revenue
- Gross profit and break-even
- Alerts and health indicators
- Inventory adjustments
- Archive action

## Customer Workspace

Core areas:

- Customer identity
- Addresses
- Order history
- Lifetime value
- Average order value
- Favorite sizes, brands, notes, and fragrance families
- Internal notes
- Communication context
- Delivery and payment preferences
- Tags
- Purchase timeline
