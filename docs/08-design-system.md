# Design System

## Design Direction

### Customer Website

- 70% modern minimal
- 30% editorial luxury

### Admin Platform

- 80% contemporary tech-luxury
- 20% modern minimal

## Personality

- Calm
- Precise
- Refined
- Premium
- Modern
- Spacious
- Intelligent
- Respectful

## Typography

- Display and editorial headings: Canela
- Body and interface text: Manrope

## Iconography

- Hugeicons

Icon usage should remain restrained and functional.

## Layout Foundations

### Website

- 12-column responsive grid
- Reading width around 760 px
- Standard content width around 1280 px
- Maximum content width around 1440 px

### Admin

- Collapsible sidebar
- Fluid workspace
- Optional right inspector panel
- Consistent page and section wrappers

## Spacing Scale

- 4 px
- 8 px
- 12 px
- 16 px
- 24 px
- 32 px
- 48 px
- 64 px
- 96 px

## Radius Guidance

- Inputs and buttons: approximately 10 px
- Cards: approximately 16 px
- Dialogs and large media: approximately 20 px
- Pills and badges: full radius

## Motion

Motion should explain rather than entertain.

- Hover: approximately 120 ms
- Button feedback: approximately 150 ms
- Drawer: approximately 220 ms
- Dialog: approximately 250 ms
- Page transition: approximately 300 ms

Respect reduced-motion preferences.

## Accessibility

- Strong focus indicators
- Keyboard navigation
- Color is never the only status indicator
- Accessible labels and screen-reader support
- Sufficient contrast
- Touch-friendly targets
- Loading, empty, error, and disabled states
